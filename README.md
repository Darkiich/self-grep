# self-grep

Простая консольная утилита для поиска текста в файлах (аналог `grep`), написанная на C специально для Windows.

Поддерживает поиск по нескольким файлам, вывод с подсветкой, поиск без учёта регистра и замер времени выполнения.


## Возможности
- Поиск строки в одном или нескольких файлах
- Подсветка найденных результатов цветом
- Поиск с учётом / без учёта регистра (`-i`)
- Подробный и краткий режимы вывода (`-sm`)
- Подсчёт количества вхождений
- Замер времени поиска
- Поддержка длинных и коротких флагов


## Особенности
Работает только на Windows (использует WinAPI)
Кодировка консоли: Windows-1251
Цветной вывод результатов
При указании нескольких файлов через -p поиск выполняется по всем


## Использование
```bash
grep.exe -p <файл> -s <строка> [-sm 0|1] [-i]
```


### Параметры
| Флаг                  | Длинный флаг       | Описание                                                                 | Обязательный |
|-----------------------|--------------------|--------------------------------------------------------------------------|--------------|
| `-p`                  | `--path`           | Путь к файлу (можно указывать несколько раз)                             | Да           |
| `-s`                  | `--str`            | Строка для поиска                                                        | Да           |
| `-sm`                 | `--show-more`      | Подробный вывод информации (1 — да, 0 — нет). По умолчанию: `1`          | Нет          |
| `-i`                  | `--ignore-case`    | Игнорировать регистр при поиске                                          | Нет          |
| `-h`                  | `--help`           | Показать справку                                                         | Нет          |


## Примеры использования
```bash
# Обычный поиск
grep.exe -p notes.txt -s "важно"

# Поиск в нескольких файлах
grep.exe -p file1.txt -p file2.txt -s "ошибка"

# Поиск без учёта регистра
grep.exe -p log.txt -s Error -i

# Краткий вывод (только количество)
grep.exe -p data.txt -s "ключ" -sm 0

# Подробный вывод с номерами строк
grep.exe --path report.txt --str "итог" --show-more 1
```
